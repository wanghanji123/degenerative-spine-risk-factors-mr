# Figure set

The directory contains the 14 figures corresponding to Review4.0. Figure 12 was updated in Review3.9 to include the MVMR covariance-assumption stress test. The source caption inventory is provided as `figure_table_caption_inventory.csv`.

Figures 5, 7, 8, and 14 are interpretive or workflow schematics. They should not be treated as additional statistical analyses. Figure 11 is an illustrative overlap scenario analysis. Figure 13 reports standardized MRlap sensitivity estimates rather than primary odds ratios.

Figures 5 and 7 contain non-data-bearing illustration layers initially generated with OpenAI GPT Image 2. All labels, arrows, numerical results, and caveats were added or verified by the authors. These two figures require target-journal policy review; replace their AI-assisted layers with deterministic author-drawn/vector elements when the selected journal does not permit generative-AI illustrations or graphical abstracts.
